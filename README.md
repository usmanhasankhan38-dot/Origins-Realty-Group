# Origins Realty Group — Luxury Real Estate Website

High-performance, ultra-luxury, and visually immersive multi-page website for **Origins Realty Group** (Santa Fe & Northern New Mexico real estate brokerage), built with modern Neumorphic (Soft UI) aesthetics, Lenis smooth scrolling, GSAP animations, and 3D perspective tilt interactions.

## 🌟 Multi-Page Structure
1. **`index.html`** — Homepage with Editorial Architectural Hero, property search console, heritage story, and stats bar.
2. **`about.html`** — Deeply Rooted in Northern New Mexico heritage, banking/engineering/education multidisciplinary background, and fiduciary pillars.
3. **`properties.html`** — Curated portfolio with interactive category filters (*All*, *For Sale*, *Sold*), 3D tilt cards, and architectural modal details.
4. **`communities.html`** — Santa Fe, Eldorado & Galisteo, Los Alamos & White Rock, Pecos, Nambe Valley, and Albuquerque regional guides.
5. **`team.html`** — Licensed broker profiles with NM license numbers, credentials, and direct contact buttons.
6. **`testimonials.html`** — Verified client reviews, 5-star ratings, and seller/buyer acclaim.
7. **`contact.html`** — Tactile Neumorphic inquiry form with inset fields, location details, phone lines, and Fair Housing compliance.

## 🚀 Deployment
Pre-configured for instant deployment on [Vercel](https://vercel.com) via `vercel.json` with clean URLs and static asset caching.
